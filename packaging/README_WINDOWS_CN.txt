Crayotter Windows 使用说明
=========================

1. 请完整解压 Crayotter-Windows-x64.zip，不要直接在压缩包内运行。
2. 双击 Crayotter.exe。
3. 首次使用请在工作台“设置”中填写 API Key 和模型配置。
4. 运行数据、上传素材、日志和成品默认保存在本目录。
5. 如果本目录不可写，运行数据会保存到 %LOCALAPPDATA%\Crayotter。
6. 如果电脑缺少 Microsoft Edge WebView2，工作台会自动在默认浏览器中打开。
7. 如果 Windows 提示未知发布者或 SmartScreen 风险，说明当前 exe 未使用受信任代码签名证书签名；生产发布建议使用可信证书签名后再分发。

请勿移动或删除 _internal 目录；它包含程序运行所需依赖。
