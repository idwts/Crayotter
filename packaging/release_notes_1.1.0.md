Crayotter 1.1.0 现已支持 Windows 和 macOS 桌面使用。

- 提供 Windows 和 Apple Silicon Mac 安装包，解压后即可打开工作台。
- 自带视频处理工具，无需单独安装 Python 或 FFmpeg。
- 改善配音、字幕显示和素材剪辑体验。

**下载选择**

- Windows 10/11 x64：`Crayotter-Windows-x64.zip`
- macOS 15 及以上、Apple Silicon：`Crayotter-macOS-arm64.zip`

首次使用请在“设置”中填写自己的模型 API 配置。Mac 包尚未通过 Apple 公证，系统可能要求确认后才能打开。
